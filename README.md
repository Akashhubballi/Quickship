# QuickShip™ – Courier & Delivery Platform

A modern, responsive courier and parcel delivery website prototype built using **HTML5 and CSS3**. QuickShip provides a clean and user-friendly interface for exploring delivery services, booking courier shipments, tracking parcels, and contacting the logistics team.

## 📦 Project Overview

QuickShip is a multi-page logistics website designed to demonstrate modern frontend development concepts and responsive web design.

### Key Features

- **Home Page:** Introduction to QuickShip, delivery services, tracking section, and customer reviews.
- **Courier Booking:** Booking form with sender details, receiver details, parcel information, and delivery options.
- **Parcel Tracking:** Tracking interface with shipment details and delivery milestone timeline.
- **Delivery Services:** Overview of same-day delivery, express shipping, ground delivery, and freight services.
- **Contact Page:** Contact information, inquiry form, and frequently asked questions.
- **Responsive Design:** Optimized layouts for mobile phones, tablets, laptops, and desktops.
- **Pure HTML & CSS:** Developed without JavaScript, Bootstrap, Tailwind CSS, or external UI frameworks.

## 🚀 How to Run the Project

No installation, build tools, or additional dependencies are required.

### Option 1: Open Directly in Browser

1. Download or clone the project from GitHub.
2. Extract the project folder if downloaded as a ZIP.
3. Open the `quickship` folder.
4. Double-click on `index.html`.
5. The website will open in your default browser.

### Option 2: Using VS Code Live Server

1. Open the project folder in Visual Studio Code.
2. Install the **Live Server** extension if it is not already installed.
3. Right-click on `index.html`.
4. Select **Open with Live Server**.
5. The website will open in your browser.

Example local URL:

`http://127.0.0.1:5500/index.html`
